## Vai trò của V2

V2 là module chính thức cho:

- Fitness Check
- Personal Plan
- Kế hoạch sức khỏe
- Kế hoạch tập luyện
- Kế hoạch dinh dưỡng
- Workout Session
- Video hướng dẫn bài tập

V1 vẫn là website SPORTHUB chính cho:

- Trang chủ
- Giới thiệu
- Sản phẩm
- Blog
- Liên hệ
- Giỏ hàng
- Thanh toán
